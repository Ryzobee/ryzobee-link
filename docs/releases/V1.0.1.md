# V1.0.1 · AI 浏览器控制正式上线

组织仓库 `Ryzobee/ryzobee-link` 在 V1.0.0 基础上新增 AI 浏览器控制，继续保持纯前端、无后端部署。

## ✨ 新增

- 标准 MCP JSON-RPC 接口与 24 个工具，覆盖 Lua 草稿、UI 模拟器、设备脚本和日志。
- 独立 AI 命令页 `agent.html`，支持同浏览器会话发现、控制授权与请求结果查询；用户页继续持有串口、编辑器和模拟器。
- AI 可读取、创建和修改草稿，启动仿真、模拟触摸并获取 PNG 截图；代码与画面同步显示在用户页。
- 设备信息、文件读取、上传、运行和停止工具。上传与运行分离，设备执行不需要先通过仿真，也不新增审核令牌。
- 独立 `ryzobee-link` skill，配套中英文安装说明、图文上手指南和真实页面截图；与负责 Lua 编写的 `ryzobee-lua` 分开使用。

## 🛡️ 可靠性

- 唯一请求 ID、源码 hash、写前授权检查，避免重复执行与覆盖用户修改；超时后查询原请求，不自动重发写入或运行。
- 设备断开、重启或用户结束控制后撤销授权；日志支持增量查询和截断提示。
- 离线资源按部署路径管理，静态构建同时包含用户页、AI 页和 Lua/LVGL Wasm 模拟器。

## 边界与版本说明

消息采用 MCP 标准，但使用浏览器自定义传输，不是可直接填入普通 MCP 客户端的 HTTP endpoint。AI 需要浏览器操作能力；设备连接仍需用户选择串口。UI 仿真不代表实体外设验证。本次不修改固件。

个人 fork 已发布的 V1.1.0 是该功能的预览版本，标签和历史验收保持不变；组织正式版采用 V1.0.1，二者各自发布，不覆盖或移动旧标签。预览版的测试及线上交互证据见 [验收记录](https://github.com/Ryzobee/ryzobee-link/blob/V1.0.1/docs/validation-v1.1.0.md)。

## English summary

Adds browser-based MCP tool control, a separate AI companion page, session approval, shared Lua drafts and interactive UI simulation, independent device upload/run operations, incremental logs, and a standalone `ryzobee-link` skill with illustrated bilingual guides. No backend, embedded model credentials, simulation gate, or firmware changes are required. The official release is V1.0.1; the previously published fork preview V1.1.0 remains unchanged.
