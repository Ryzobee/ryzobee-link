# V1.1.0 · 浏览器 AI 命令接口

RYZOBEE LINK 继续保持纯静态部署，本版让具备浏览器工具的 AI 使用结构化命令参与编辑、UI 仿真与设备联调。

## ✨ 新增

- 主页面公开 `window.ryzobeeLink`；独立 `agent.html` 提供普通文本框、会话选择和 JSON 结果，主界面不新增跳转入口。
- 同浏览器/同源会话发现、本次控制授权、顶栏结束控制；未连接时在用户页弹出串口连接提示。
- 草稿的列表、读取、新建、更新、选择、关闭；AI 更新会立即同步 Monaco，使用源码 hash 防止覆盖用户的并行修改。
- 共享模拟器的启动、状态查询、停止、按下/释放、PNG 截图；返回 runId、源码 hash、帧修订号和故障信息。
- 设备信息、目录、读取、上传、运行、任务查询及停止；上传与运行分离，设备运行不以仿真为前置条件。
- 按 runId/jobId 查询有界增量日志，返回游标和丢失提示。
- 独立 `ryzobee-link` skill 及中英文安装/使用说明。既有 `ryzobee-lua` 继续负责脚本编写与官方固件接口查证，没有合并两者职责。

## 🛡️ 行为约束

- 同一请求编号防重复执行；结果未知时可查原请求，不自动重传写入/运行。
- 主页面重载、设备断开或检测到重新启动后撤销授权；串口真正写入前再次检查控制权限。
- URL fragment 只预填命令，不自动执行；不暴露任意 Console、eval、设备删除或整机刷机命令。
- 使用既有设备协议、hash 完整性校验和文件版本保护；不新增仿真令牌、审核凭证或固件改动。

## 🔧 调整

- 工作区和模拟器抽为界面与命令共用的状态服务，仍只有用户页面持有串口与运行任务。
- 静态构建包含两个页面；离线缓存按部署路径隔离，支持 AI 页带 query 的离线打开。

## 使用与边界

参见[命令指南](../agent-commands.md)和 [ryzobee-link skill](../../skills/ryzobee-link/README.md)。授权用于可信同源环境，不是对恶意同源脚本的认证防护。后台页可能冻结；关闭所有页面后没有常驻 AI 服务。串口需要用户主动选择，模拟器只覆盖 UI，不代表物理外设通过。

本标签首先发布到个人 fork：`https://geekheart.github.io/ryzobee-link/`。组织正式发布需合并 PR 并在组织仓库单独打标签。验收记录见 [V1.1.0 验证](../validation-v1.1.0.md)。

## English summary

Adds a pure-browser command interface, a separate AI companion page, session-scoped user approval, shared document/simulator services, independent device upload/run commands, bounded incremental logs and a standalone `ryzobee-link` skill. Idempotent request IDs and source hashes protect against unintended replays and stale edits. No backend, model API key, simulation gate or firmware changes are required. The trust boundary is the entire origin; browser lifecycle and serial user-gesture requirements still apply.
