# V1.0.0 · RYZOBEE LINK

首个正式版本。面向 Ryzobee RootMaker 的轻量 Lua 工作台：**在浏览器中编写、模拟、发送和调试脚本**。这是 Link 网页工具的版本号，不是设备固件版本。

本次为首次发行，功能记录仅列「新增」，不设置「修改」或「删除」栏目。

## 新增

### Lua 多文件工作区

- Monaco Lua 编辑器、语法高亮、自适应宽度文件标签；支持横向滚动、完整文件名悬停查看及逐个关闭。
- 新建 Lua 脚本使用固件可识别的 `ryz-app/1` 元数据头，包含作者、版本和简介；内置可交互计数器示例。
- 批量打开本地 Lua 文件、读取设备文件到独立标签、导出当前文件。同名不同内容的文件独立保留。
- 多文件草稿和当前标签自动保存到浏览器 IndexedDB；关闭最后一个标签保留空工作区。
- 离开页面时使用浏览器原生确认；关闭编辑器标签仅移除该浏览器草稿，不删除电脑或设备文件。

### 交互式 UI 模拟器

- Ryzobee C 应用运行时、Lua 解释器和 LVGL 经 Emscripten 构建为 WebAssembly；不是预录动画，也不是 JavaScript 伪造执行结果。
- 240×240 模拟屏幕，鼠标/指针触摸输入，实时渲染与脚本日志。
- 支持 `ui.mount/update/poll`、当前运行时基础 Lua/board 能力及 legacy RGB565 canvas 显示。
- 单一运行/停止图标；每次运行创建独立 Worker/VM，只加载点击运行时的源码，编辑和切换标签不暗中重启。
- 待机画面、屏幕边框及错误画面遵循设备视觉风格；具体诊断进入 Link 日志。
- 协作停止和浏览器 Worker 超时终止，故障后可以重新运行，不操作真实设备。

### Web Serial 设备文件与执行

- 从浏览器主动授权 USB 串口，识别支持 `ryz-script-store/1` 的 RootMaker 固件，115200 波特率。
- 文件列表、选中数量和容量信息；连接、写入、删除后自动刷新。
- 双击读取文件；文件菜单提供读取、下载、运行和删除；支持停止设备脚本。
- 将当前 Lua 源码发送到设备，确认弹窗默认勾选「发送后自动运行」；成功写入后启动，取消勾选则仅保存。
- SHA-256 与长度校验、设备文件版本冲突保护、覆盖和删除确认，遵循设备报告的文件保护状态。
- 断线或超时无法确定写入结果时显示「结果未知」，不自动重发写入或运行；浏览器断开不停止持续供电的设备脚本。
- 发送设备独立于模拟器，不要求仿真通过、审核令牌或额外认证步骤。

### 日志与操作体验

- 「全部 / 设备串口 / 模拟器 / Link」来源标签，级别筛选、行数、暂停滚动和清空视图。
- 有界日志缓存和虚拟列表；设备输出作为文本安全呈现，支持 ANSI 样式解析。
- 顶部集中「打开 / 保存 / 发送 / 连接」，通知置于状态栏，避免挤占工作区。
- Ryzobee 配色与本地字体、Codicons 图标、桌面和窄屏响应式布局。
- `Ctrl/⌘+O` 打开、`Ctrl/⌘+S` 保存、`Ctrl/⌘+Enter` 运行/停止、`Ctrl/⌘+Shift+Enter` 打开发送确认、`F1` 快捷键帮助；悬停显示快捷键。

### 静态部署与离线使用

- React + TypeScript + Vite 纯前端，无账号、云端业务服务或桌面安装包要求。
- 编辑器 Worker、字体、图标、模拟器 JS/Wasm 随应用分发，不依赖运行时 CDN。
- 完整生产资源缓存成功后可离线重开；更新等待旧页面关闭，不强制打断工作。
- 支持 HTTPS 静态托管与子目录部署；版本标签驱动 GitHub Actions 构建并更新 Pages，普通提交和 PR 不触发发布。

### 开源资料与 AI 辅助技能

- 中英文 README、实际界面截图、架构、使用约束、部署与发布指南。
- 独立 `skills/ryzobee-lua/` 技能包及中英文安装说明，指导外部 AI 按固件契约编写 Lua；用户包不包含维护者测试集。
- MIT 开源协议、第三方授权与字体/图标署名、固定 emoji + type(scope) 提交规范及 PR 检查。

## 使用条件与范围

- 设备连接主要面向支持 Web Serial 的桌面 Chrome / Edge；HTTPS、USB 驱动、系统权限和未被占用的串口仍是必要条件。
- 当前兼容协议中的 Lua 文件上限为 16 KiB；文件名主体为 1–36 位 ASCII 字母、数字、`_`、`-`，扩展名为 `.lua`。固件运行脚本期间拒绝文件读写，需先停止设备脚本。
- 模拟器主要验证纯 UI 交互，不模拟真实外设、电气、无线、DMA 或 ESP32 实时性能。模拟成功不代表实机通过。
- 不包含整机固件烧录/擦除、Lua REPL、自启脚本设置、内置 AI 对话或 MCP 服务。外部 skill 不会给 Link 增加 AI 后端。
- 首次访问需联网并完成缓存。草稿保存在当前浏览器及站点；不同域名、localhost 与线上站点不会共享草稿或串口授权，请导出重要文件。
- GitHub Actions 构建、浏览器仿真和实机测试是不同层次的证据；本说明描述功能范围，不将历史实机记录当作本次发版验证。

## English summary — Added

The first RYZOBEE LINK release brings a browser-based Lua workbench for RootMaker:

- A Monaco multi-file editor, firmware-compatible metadata templates, local file import/export and persistent browser drafts.
- Interactive 240×240 Lua/LVGL WebAssembly UI simulation in isolated Workers, with pointer input and run/stop controls.
- Web Serial discovery, device file listing/storage usage, read/download/upload/delete, and script run/stop. Upload can automatically run the saved script after confirmation; simulation is never an upload prerequisite.
- Source-filtered logs, level filtering, keyboard shortcuts, responsive panels and self-hosted Ryzobee typography/icons.
- Static HTTPS hosting, offline caching after a successful first load, and version-tag-triggered GitHub Pages deployment.
- Bilingual documentation, real UI screenshots, an installable external Lua AI skill, MIT licensing and contribution conventions.

This version identifies the web tool, not board firmware. Hardware requires compatible `ryz-script-store/1` firmware and browser/OS serial support. The simulator is UI-focused, not full ESP32/peripheral emulation. Full firmware flashing, built-in AI chat and a Lua REPL are outside this release.
